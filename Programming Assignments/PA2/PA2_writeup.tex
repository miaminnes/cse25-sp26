\section*{Overview}
In this assignment you will implement n-gram language models and train them to
generate text using Tiny Shakespeare. All graded tasks are marked with TODO
comments in \texttt{PA2.ipynb}.

\section*{Learning Goals}
\begin{itemize}
  \item Understand text preprocessing and tokenization for language modeling.
  \item Implement a unigram model based on word frequencies.
  \item Implement a bigram model for next-word prediction with one word of context.
  \item Evaluate language models using log probability and perplexity.
  \item Generate Shakespeare-like text from trained language models.
\end{itemize}
