\section*{Overview}
In this assignment you will implement tabular Q-learning for Nim, a two-player
turn-based strategy game. Player 0 learns from simulated games against simple
opponents, then evaluates the learned greedy policy. All graded code tasks are
marked with TODO comments in \texttt{PA3.ipynb}; Question 4 is a short manual
response using the reporting cell near the end of the notebook.
